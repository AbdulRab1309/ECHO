# ⚡ ECHO – Electronics E-Commerce Store

ECHO is a modern electronics e-commerce web application designed for students, makers, developers, and electronics enthusiasts. It provides a clean shopping experience for browsing electronic components, viewing detailed specifications, searching products, managing a shopping cart, and completing a checkout flow.

This project was built to combine my passion for **Electronics & Communication Engineering (ECE)** with modern web development technologies.

---

## 📖 Overview

The goal of this project is to create a modern electronics storefront that focuses on usability, responsive design, and a smooth user experience.

The application includes product browsing, category filtering, product search, shopping cart management, checkout flow, contact page, and multiple UI themes.

---

## ✨ Features

* 🛒 Electronics e-commerce interface
* 🔍 Instant product search
* 📂 Browse products by category
* 📄 Detailed product pages with specifications
* ➕ Add to Cart functionality
* 💳 Checkout workflow
* 📬 Contact page
* 📱 Fully responsive design
* 🎨 Three built-in themes

  * Light
  * Dark
  * Red
* ⚡ Smooth animations using Framer Motion
* 🧾 Form validation using React Hook Form + Zod
* 🧠 Global state management using Zustand

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/AbdulRab1309/E-Commerce-Full-Stack.git
```

Move into the project directory.

```bash
cd E-Commerce-Full-Stack
```

Install dependencies.

```bash
npm install
```

Start the development server.

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```
